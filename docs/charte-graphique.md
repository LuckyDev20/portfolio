# Charte graphique — Portfolio de Loukman Ouedraogo

> Version 1.0 — Novembre 2026
> Identité : **sérieux, moderne, créatif**
> Palette retenue : **Option 1 — Bleu nuit et cyan** (thème sombre)

**Pourquoi ce choix :** ces couleurs reflètent mon sérieux et mon professionnalisme en tant que développeur, prêt à innover.

---

## 1. Couleurs

### Fonds
| Nom | Code | Usage |
|---|---|---|
| Fond principal | `#0F172A` | Fond de la page |
| Fond secondaire | `#1E293B` | Cartes (projets, compétences), formulaire |
| Bordure | `#334155` | Contours des cartes et des champs |

### Couleurs de marque
| Nom | Code | Usage |
|---|---|---|
| Bleu principal | `#1E40AF` | Éléments de marque : fonds de badges, survols, décorations |
| Bleu clair | `#60A5FA` | Liens et textes en bleu (lisible sur fond sombre) |
| Accent cyan | `#06B6D4` | **Boutons d'action principaux**, éléments à mettre en avant |
| Texte sur cyan | `#083344` | Texte des boutons cyan |

### Textes
| Nom | Code | Usage |
|---|---|---|
| Texte titre | `#F8FAFC` | Titres, nom |
| Texte courant | `#CBD5E1` | Paragraphes |
| Texte discret | `#94A3B8` | Légendes, dates, informations secondaires |

### Règles d'usage
- **60-30-10** : 60 % fonds sombres, 30 % textes et bleus, 10 % cyan.
- Le **cyan est réservé aux actions** (boutons, liens importants). S'il est partout, il n'attire plus l'œil.
- Le bleu principal `#1E40AF` n'est **jamais utilisé pour du texte** sur fond sombre : contraste insuffisant. Pour du texte bleu, utiliser `#60A5FA`.
- Paragraphes en `#CBD5E1` plutôt qu'en blanc pur : moins de fatigue visuelle sur fond sombre.

## 2. Typographie

| Rôle | Police | Graisse |
|---|---|---|
| Titres | **Space Grotesk** | 500 à 700 |
| Texte | **Inter** | 400 (normal), 500 (mis en avant) |

Polices gratuites, disponibles sur Google Fonts.

### Tailles (mobile → ordinateur)
| Élément | Mobile | Ordinateur |
|---|---|---|
| Nom (titre principal, H1) | 32 px | 56 px |
| Titres de section (H2) | 24 px | 36 px |
| Sous-titres (H3) | 18 px | 22 px |
| Texte courant | 16 px | 18 px |
| Petit texte | 14 px | 14 px |

Interligne du texte courant : **1,6**.

## 3. Espacements

Tous les espacements sont des **multiples de 8 px** : 8, 16, 24, 32, 48, 64, 96.
- Marges sur les côtés : 16 px (mobile), 32 px ou plus (ordinateur).
- Espace entre deux sections : 64 px (mobile), 96 px (ordinateur).
- Largeur maximale du contenu : 1200 px.

## 4. Composants

- **Coins arrondis** : 8 px pour les boutons et champs, 12 px pour les cartes.
- **Bouton principal** : fond cyan `#06B6D4`, texte `#083344`.
- **Bouton secondaire** : fond transparent, bordure `#475569`, texte `#F8FAFC`.
- **Cartes** : fond `#1E293B`, bordure `#334155`.

## 5. Accessibilité

- Contraste du texte d'au moins **4,5:1** avec son fond (norme WCAG AA).
- Un contour visible sur les éléments sélectionnés au clavier (focus).
